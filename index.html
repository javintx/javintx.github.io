Hola, soy Javier.

Ingeniero de software. Me interesa entender el problema antes que escribir código.

Qué hago

Trabajo como ingeniero de software, principalmente en entornos donde la calidad, la claridad y la mantenibilidad importan tanto como que el sistema funcione.

He participado en proyectos a largo plazo, con código que evoluciona, requisitos cambiantes y decisiones técnicas que tienen impacto real.

Cómo trabajo

Intento trabajar de forma pragmática:

  • Entender el problema y su contexto
  • Diseñar soluciones que se puedan explicar
  • Escribir código sencillo, testeable y mantenible
  • Evitar la complejidad innecesaria
  • Aplicar SOLID y principios de Clean Code en el desarrollo

Áreas técnicas

Backend con Java, Kotlin y Scala. Diseño de APIs REST, sistemas distribuidos, integración con sistemas legacy, hexagonal architecture, TDD, testing unitario y end-to-end, arquitectura y buenas prácticas.

Stack tecnológico

  • Lenguajes: Java, Kotlin, Scala
  • Frameworks: Spring Boot, Gradle, JUnit5, Mockito, RestAssured
  • Patrones: Hexagonal Architecture, TDD, Test-Driven Development
  • Otros: Docker, APIs REST, Autenticación JWT, SonarCloud, CI/CD

Proyectos destacados

  • The CRM Service: API REST para gestión de clientes con autenticación JWT, arquitectura hexagonal y testing exhaustivo. Implementado con Spring Boot y desarrollado con TDD.
